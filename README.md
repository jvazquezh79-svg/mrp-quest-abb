# MRP Quest ABB

Juego educativo bilingüe de 16 bits para practicar MPS y MRP mediante una aventura interactiva.

## Jugar

Abre el sitio publicado en GitHub Pages:

https://jvazquezh79-svg.github.io/mrp-quest-abb/

El juego funciona en computadora y teléfono móvil, en orientación vertical u horizontal. Incluye controles táctiles, escenarios variables, actividades de demanda, MPS, BOM, MRP y Control Tower, además de un reporte final en PDF.

## Arte

El juego usa pixel art estilo SNES de 16 bits (inspirado en Final Fantasy VI): resolución interna de 480×270, tiles de 16 px, sprites de 16×24 con cuatro direcciones y animación de caminado, retratos de 24×24 y ventanas azules con marco blanco.

Todo el arte vive en `pixelart.js` como texto (un carácter = un píxel) y se rasteriza al cargar; no hay imágenes externas. Para publicar se necesitan los dos archivos: `index.html` y `pixelart.js`.
