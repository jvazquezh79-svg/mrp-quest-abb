# MRP Quest ABB

Juego educativo bilingüe de 16 bits para practicar MPS y MRP mediante una aventura interactiva.

## Jugar

Abre el sitio publicado en GitHub Pages:

https://jvazquezh79-svg.github.io/mrp-quest-abb/

El juego funciona en computadora y teléfono móvil, en orientación vertical u horizontal. Incluye controles táctiles, escenarios variables, actividades de demanda, MPS, BOM, MRP y Control Tower, además de un reporte final en PDF.
